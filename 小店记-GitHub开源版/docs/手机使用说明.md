# 手机使用说明

## 打开自己的站点

在手机浏览器输入维护者部署得到的 HTTPS 网址，固定用这一个浏览器。第一次联网完整打开后，可以通过浏览器菜单“添加到桌面”或“收藏”。没有安装选项也可以直接在浏览器使用。

不要用无痕模式，也不要把微信内置浏览器和系统浏览器混着当作同一套数据库使用。

## 日常操作

1. 先添加供应商和商品，再用“登记现有库存”填写货架上已有的数量和到期日。相同商品不同到期日分批登记。
2. 新货实际到了，点“记录到货”，填数量、实际总金额和到期日，核对后保存。
3. 准备补货时，先在“商品”中按批次核对实际数量，再去“更多 → 补货清单”整理。
4. 每天查看“临期”，按包装确认日期并处理。优先销售/打折只是标记；售完、退货或下架清零需要确认。

## 保存和备份

改完资料，点“核对并保存”，再点“确认保存”。看到“已保存到本机”才表示浏览器数据库写入成功。

保存后点“导出最新备份”，也可以直接选择“保存并导出备份”。到文件管理的下载目录找到 `小店记备份-日期-第几版.json`，确认文件存在后才点“我已保存好文件”。每天收店时最好把最新文件另外保存到其他设备。

关闭网页再打开可以读取记录，但清理网站数据、卸载浏览器、丢失手机等可能导致记录丢失。页面内的持久存储申请并不代替备份。

## 恢复或换手机

在新设备上打开自己的站点，进入“更多 → 备份与恢复”，选择原设备导出的 JSON 文件。检查日期和记录数量，确认后恢复。

恢复会替换当前数据，不会合并；导入前可先导出当前记录。误恢复后，可使用“查看并找回”恢复最近一次导入前的数据。

## 需要知道

微信收款不自动扣库存，库存需要现场核对。日期以商品包装为准，关闭网页后不会推送临期通知。软件不做自动订货或实际付款。
