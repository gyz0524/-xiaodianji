# 参与改进

欢迎提交问题和改进建议。

## 报告问题

请描述浏览器和设备、操作步骤、预期结果与实际结果。如提供截图或备份示例，请使用虚构测试数据，不要公开真实联系方式、库存账目或授权信息。

## 修改代码

1. Fork 仓库，在自己的副本创建分支。
2. 运行 `npm ci` 和 `npm run dev`。
3. 每次集中修改一个问题。涉及库存、金额、日期或数据恢复时，添加覆盖实际行为的测试。
4. 运行 `npm test`、`npm run build`；涉及表单或交互时再运行 `npm run test:browser`，并检查手机显示。
5. 提交 Pull Request，说明改动、原因和验证结果。维护者审核并合并后，才会进入原仓库。

不要提交 `node_modules`、构建目录、店铺 JSON 备份、环境密钥、`.netlify` 或托管授权文件。

更改数据结构时，请同时说明对已有浏览器数据和旧备份的兼容或迁移方案。遵循本项目的 MIT 许可证和第三方依赖许可证。
